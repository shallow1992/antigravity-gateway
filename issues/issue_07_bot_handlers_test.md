# Issue #7: [Test] Slackイベントハンドラーの結合テストスイート追加 (test_bot_handlers.py)

## 📌 概要
Slack Bolt の `app_mention` や `message`（DM・スレッド継続・チャンネルモード）イベントハンドラーに対する結合テストを追加し、イベント受信から認可判定、プレースホルダー更新、エージェント実行、回答送信、リアクション付与までの一連のパイプラインをモックで網羅的に検証する。

## 🎯 目的
実際の Slack 接続なしで、Bot のイベントハンドラー全体の動作保証を行い、実機セットアップ時の手戻りを防ぐ。

## 🔍 テスト対象シナリオ
1. **認可ユーザーによる `@bot` メンション**:
   - `reactions_add` (eyes) ➔ `chat_postMessage` (placeholder) ➔ `agent_runner.execute_prompt` ➔ `chat_update` (final) ➔ `reactions_add` (check_mark) の一連の呼び出し。
2. **未認可ユーザーによるメンション**:
   - 即座に「⚠️ 実行権限がありません」が返り、エージェントが実行されないこと。
3. **未認可チャンネルでのメンション**:
   - 無視されるか、適切なエラーが返ること。
4. **DM 受信**:
   - メンションなしで直接対話が成立すること。
5. **スレッド継続対話**:
   - 既存セッションが存在するスレッドで、メンションなしメッセージが正しくエージェントに渡ること。
